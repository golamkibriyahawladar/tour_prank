# Tour Plan (ট্যুর প্ল্যান)

> **Tour Plan (ট্যুর প্ল্যান)** — ইন্টারেক্টিভ বাংলাদেশ ও বিশ্ব ভ্রমণ মানচিত্র ট্র্যাকার এবং ভাইরাল **"ক্যান্সেল ট্যুর"** নন-জুডিশিয়াল স্ট্যাম্প পেপার মেম জেনারেটর।

---

## 🌟 প্রধান ফিচারসমূহ (Key Features)

### ১. আমার বাংলাদেশ (Bangladesh 64 District Map)
- 🗺️ বাংলাদেশের সকল **৬৪টি জেলা** ভেক্টর এসভিজি (SVG) ম্যাপে নির্বাচন ও ট্র্যাক করার সুবিধা।
- 🎨 ৫টি প্রিমিয়াম থিম: এমারেল্ড গ্রিন, সানসেট অরেঞ্জ, ওশান ব্লু, মিডনাইট ডার্ক, গ্রিন নাইট।
- 🔍 আল্ট্রা-শার্প জুম: কোনোভাবেই জেলা বা মানচিত্র ফাটবে না।
- 📥 **4K Ultra HD PNG (4000px+), 4K JPG, Infinite Vector SVG** এবং ইনস্টাগ্রাম/ফেসবুক **Story 9:16** ফরম্যাটে ডাউনলোড।

### ২. 📜 ক্যান্সেল ট্যুর সমিতি (Canceled Tour Meme Mode - Non-Judicial Stamp Paper)
- ⚖️ হুবহু বাংলাদেশি **১০০ টাকার নন-জুডিশিয়াল স্ট্যাম্প পেপার** ডিজাইন।
- 🏛️ বড় ও বোল্ড হেডার: **"ট্যুর ক্যান্সেল সমিতি কর্তৃক অনুমোদিত"**।
- 🛡️ অফিশিয়াল রাবার স্ট্যাম্প: **"★ ভুয়া বন্ধু সার্টিফাইড ★"** ও **"১০০% ধোঁকাবাজ"** সিলমোহর (কোনো জেলা সিলেক্ট করলেও সিলের সাথে ক্ল্যাশ করবে না)।
- ✍️ বাদি (ভুক্তভোগী) ও বিবাদী (কালপ্রিট বন্ধুগণ)-এর নাম সংযোজন।
- 🤦‍♂️ ১২টি রিয়েল অজুহাত (ধারা ৪২০, ধারা ৮৪০) নির্বাচন।
- 💬 পাঞ্চলাইন ড্রপডাউন + কাস্টম ডায়ালগ এবং ১-ক্লিকে ডায়ালগ র‍্যান্ডমাইজ করার অপশন।
- 👨‍⚖️ কালপ্রিটদের শাস্তির রায় (যেমন: আগামী ১ বছর সব চায়ের বিল কালপ্রিটরা বহন করিবে)।

### ৩. বিশ্ব মানচিত্র (World 194 Country Map)
- 🌍 বিশ্বের **১৯৪টি দেশ** ট্র্যাক ও কালার করার সুবিধা।
- 🇧🇩 বাংলাদেশ স্পটলাইট পিন: ওয়ার্ল্ড ম্যাপে বাংলাদেশকে আলাদাভাবে হাইলাইট করার স্পেশাল ফিচার।
- 🌐 মহাদেশ অনুযায়ী দ্রুত ফিল্টার এবং সার্চিং।

## 🚀 টেকনোলজি স্ট্যাক (Tech Stack)

- **Framework:** Next.js 16 (App Router & Turbopack)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Icons:** Lucide React
- **Canvas Rendering:** HTML5 Canvas (High-DPI 4K & SVG Vector Export)
- **Animation & Confetti:** Canvas Confetti

## 💻 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

প্রথমে ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

ব্রাউজারে ওপেন করুন: [http://localhost:3000](http://localhost:3000)

প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
npm run start
```
